# Constructing Optimal Locally Recoverable Codes

This repository contains my Bachelor's Mathematics thesis on the construction of optimal locally recoverable codes (LRC codes).

## Context

Locally recoverable codes are error-correcting codes designed for distributed storage systems. They allow an erased symbol to be recovered by accessing only a small number of other symbols, reducing the cost of data recovery compared with classical erasure codes.

## Project Overview

The thesis studies algebraic constructions of optimal locally recoverable codes, with particular emphasis on the polynomial-evaluation framework of Tamo and Barg.

The main topics include:

- finite fields and linear codes;
- Reed–Solomon codes;
- locally recoverable codes and locality;
- Singleton-type bounds for LRC codes;
- polynomial-evaluation constructions;
- good polynomials and recovering sets;
- local recovery via polynomial interpolation;
- systematic encoding.

The work also develops explicit examples over small finite fields and explores algebraic methods for constructing good polynomials.
